## Funktionen

- **Netzwerkprofile:** IP, Subnetz, Gateway, DNS speichern und per Klick umschalten, auch über das Symbol in der Taskleiste. Mit IP-Konfliktprüfung.
- **Netzwerk privat – wichtig:** Windows stellt neue oder unbekannte Netzwerke, z.B. ein Show-Netz ohne Gateway, auf «Öffentlich». Dann blockiert die Windows-Firewall oft Show-Software wie Companion, Dante oder NDI. Netzwerk-Toolbox zeigt den Netzwerktyp an und stellt mit einem Klick auf «Privat» um. Auf Wunsch wird jedes neue Netzwerk automatisch privat, auch wenn Netzwerk-Toolbox nicht läuft.
- **DHCP-Server:** einfacher DHCP-Server mit festen Zuweisungen (MAC → IP), Hersteller-Anzeige und Zurücksetzen.
- **Monitor:** überwacht Geräte per Ping oder TCP-Port, mit Alarmton und Meldung bei Ausfall.
- **IP-Scanner:** findet alle Geräte im Netz mit Name, MAC und Hersteller.
- **Tools:** Port-Test und Wake-on-LAN.
- **Netzwerk-Info:** alle Netzwerkkarten übersichtlich, wie `ipconfig /all`.

## Installation (Windows)

1. `Netzwerk-Toolbox.exe` herunterladen und starten. Windows fragt nach Adminrechten.
2. **«Ja»** installiert das Programm (Startmenü, Desktop, Eintrag unter Apps), **«Nein»** startet es ohne Installation, z.B. vom USB-Stick.
3. Meldet Windows SmartScreen «Unbekannter Herausgeber»: **«Weitere Informationen» › «Trotzdem ausführen»**. Das Programm ist nicht digital signiert.

**Voraussetzungen:** Windows 10 oder 11 (64-Bit), sonst nichts.

**Früher «Networktool»:** Bis Version 3.3 hiess das Programm Networktool. Die Installation ersetzt es; Profile und Einstellungen werden übernommen.

**Updates:** Netzwerk-Toolbox sucht beim Start nach neuen Versionen und zeigt unten im Fenster «Update x.y.z verfügbar». Neue EXE starten und «Ja» wählen; Profile und Einstellungen bleiben erhalten.
